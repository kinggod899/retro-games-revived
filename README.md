# retro-games-revived

复活并适配经典老游戏的公开文档仓库。这里只放**文档与索引**：每款游戏做了什么修复、适配到哪个 Android 版本、去哪个 Release 下载，以及怎样把新游戏加进来。

仓库公开，采用 [MIT](LICENSE) 许可。

## 项目定位

老游戏的原始安装包往往停留在很旧的 targetSdk，在新系统上会因原生库加载规则收紧、系统库移除、广告与支付 SDK 停服等原因闪退或功能失效。本项目对每款游戏做**最小必要的修复与适配**，让它们能在当代 Android 上重新启动、正常游玩，并把可核对的技术事实沉淀成文档。

修复产出是可安装的 APK；仓库本身**不保存任何二进制**。

## 下载方式

**APK 二进制只走 Releases，不进仓库。** 仓库里没有任何 `.apk`、签名密钥或原生库，下载请到本仓库的 Releases 页面按中文资产名取用：

| 想玩什么 | 下载的 Release 资产 |
| --- | --- |
| 喵星忍者 兼容修复版 | `喵星忍者_1.08_兼容修复版.apk` |
| 小小部队 原版复活（原版经济） | `小小部队_1.0.6_原版复活.apk` |
| 小小部队 无限资源版 | `小小部队_1.0.6_无限资源版.apk` |

资产名逐字固定，改名会让下载链接与文档失配。每款游戏的具体差异与注意事项见对应 `games/<游戏中文名>/README.md`。

## 目录结构

```
retro-games-revived/
├── README.md              项目定位、速览、下载入口
├── CONTRIBUTING.md        如何添加新游戏
├── LICENSE                MIT 许可全文
├── .gitignore             二进制与密钥排除规则
├── games/                 每款游戏一个子目录，按中文名并列扩展
│   ├── 喵星忍者/
│   │   └── README.md
│   ├── 小小部队/
│   │   └── README.md
│   └── <游戏中文名>/      新增游戏：在此新建同级目录
│       └── README.md
└── engineering/           工程档案（补丁与构建记录），仅文档，不含二进制
```

`games/` 是**可扩展的扁平结构**：每加一款游戏，就加一个 `games/<游戏中文名>/` 目录，彼此不嵌套、互不影响；根目录文件不随游戏数量增长而改动。

## `games/<游戏中文名>/` 结构说明

每个游戏目录固定一个 `README.md`，承担该游戏在仓库里的全部公开信息：

| 段落 | 内容 |
| --- | --- |
| 基本信息 | 原版名、包名、版本、适配后的 targetSdk |
| 修复项 | 适配、去广告、内购、闪退根因等可核对事实 |
| 版本差异 | 存在多个变体时，逐项列出差异 |
| 下载 | 对应的 Release 资产中文名 |
| 事实来源 | 所引本地交付/接手说明的文件名 |

游戏目录**不放** APK、补丁脚本、解码树或截图；这些属于 `engineering/` 归档或 Releases 资产。

## 用途说明

- **玩家**：查该装哪个资产、两个变体有什么区别、有什么已知限制。
- **维护者**：按 `CONTRIBUTING.md` 的约定新增游戏，保证字段与命名一致。
- **接手工程师**：从「事实来源」追溯每条技术结论到原始交付说明，再结合 `engineering/` 档案复现构建。

技术事实一律以各游戏 README 末尾列出的源文件为准；文档不写本地绝对路径，也不收录账号或联系方式。
